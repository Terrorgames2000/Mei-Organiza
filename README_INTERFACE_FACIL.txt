MEI Organiza — Interface Fácil

O visual foi reorganizado pensando em pessoas com pouca familiaridade com tecnologia.

Principais mudanças:
- Tela inicial com pergunta simples: “O que você quer fazer hoje?”
- Quatro botões grandes: Adicionar conta, Registrar dinheiro que entrou, Ver contas e Calendário.
- Termos mais simples, como “Dinheiro que entrou”, “Contas do mês” e “Sobra depois das contas”.
- Informações financeiras avançadas ficam escondidas em “Ver detalhes e gráficos financeiros”.
- Botões, campos e áreas de toque maiores.
- No celular, o menu fica fixo na parte inferior para facilitar o uso com uma mão.
- Navegação com ícones e textos.
- Alertas e vencimentos continuam visíveis na tela inicial.
- A opção “Repetir todo mês” foi mantida.
- Dashboard completo, Faturamento, Calendário e Relatórios continuam disponíveis.
