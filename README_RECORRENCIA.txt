MEI Organiza — Contas Recorrentes

Nova funcionalidade:
- Ao cadastrar uma conta, existe a opção "Repetir todo mês".
- Indicada para aluguel, internet, energia, DAS, mensalidades etc.
- O sistema gera automaticamente os meses seguintes.
- A recorrência é renovada quando o usuário abre o sistema.
- Cada ocorrência pode ser paga ou editada individualmente.
- As contas recorrentes aparecem com o selo "Mensal".
- Ao desativar a repetição na conta principal, futuras ocorrências em aberto deixam de ser geradas.

A versão mantém:
- Dashboard financeiro completo.
- Faturamento.
- Contas, calendário e relatórios.
- Login/Cadastro MEI corrigido para WebView/APK.
