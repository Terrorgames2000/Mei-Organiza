Novidade:
- Modo claro (normal).
- Modo noturno.
- Botão para alternar entre os dois modos no cabeçalho.
- A preferência fica salva no navegador.
- No primeiro uso, o aplicativo pode acompanhar o tema do sistema.
- Mantém login MEI, contas, pagamentos, dashboard, calendário, relatórios, CSV e alertas.

Como testar:
1. Abra index.html.
2. Crie ou entre em um acesso MEI.
3. No topo, clique em "Modo noturno".
4. Clique novamente em "Modo claro" para voltar.
