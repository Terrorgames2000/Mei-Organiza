MEI Organiza — Tutorial separado

O tutorial NÃO abre automaticamente.

Acesso:
- Site/Desktop: botão "? Como usar" no topo.
- Celular/APK: botão flutuante "? Como usar", acima do menu inferior.

O tutorial possui 7 etapas:
1. Começando.
2. Como adicionar uma conta.
3. Como usar "Repetir todo mês".
4. Como registrar dinheiro que entrou.
5. Como marcar uma conta como paga.
6. Como entender a tela Início.
7. Calendário e lembretes.

O usuário pode avançar, voltar ou fechar a qualquer momento.
Todas as funcionalidades anteriores foram mantidas.
